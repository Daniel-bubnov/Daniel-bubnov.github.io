# Тренировки — веб-приложение

Один файл `index.html` без сборки: хостится на GitHub Pages, данные, фото и видео хранятся в Supabase.

Что умеет: планировать тренировки по датам в календаре, вести свою библиотеку упражнений (группа мышц, тренажёр и где он стоит, заметки по технике, фото тренажёра, видео ссылкой или файлом), задавать подходы с планом повторений и веса, вносить фактический результат и отмечать выполненные подходы, показывать результат прошлой тренировки прямо в карточке упражнения, копировать тренировку на другой день (фактические результаты становятся новым планом) и строить график прогресса по каждому упражнению: максимальный вес, расчётный 1ПМ, объём, повторения.

## 1. Supabase

1. Создайте проект на supabase.com.
2. Откройте **SQL Editor**, вставьте содержимое `schema.sql` и нажмите **Run**. Создадутся таблицы, правила доступа (RLS) и бакет `media` для фото и видео.
3. Создайте свой аккаунт: **Authentication → Users → Add user**, укажите email и пароль и включите автоподтверждение (Auto Confirm User).
4. Отключите регистрацию новых пользователей в настройках Authentication (опция вида «Allow new users to sign up»), чтобы никто другой не смог завести аккаунт в вашем проекте.
5. В **Project Settings → API** скопируйте **Project URL** и ключ **anon / publishable**.

## 2. Настройка файла

Откройте `index.html` и в начале блока `<script>` замените две строки:

```js
const SUPABASE_URL = 'https://ВАШ-ПРОЕКТ.supabase.co';
const SUPABASE_KEY = 'ВАШ-ANON-KEY';
```

Ключ anon можно спокойно публиковать: он виден всем посетителям сайта, но без входа в аккаунт правила RLS не дают прочитать или изменить ни одной строки. Никогда не вставляйте сюда ключ **service_role**.

## 3. GitHub Pages

1. Создайте репозиторий и загрузите в него `index.html` (README и schema.sql по желанию).
2. **Settings → Pages → Build and deployment**: Source — *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

На телефоне откройте сайт и добавьте его на главный экран («Поделиться → На экран Домой» в Safari или «Добавить на главный экран» в Chrome) — будет открываться как приложение.

## Хранение файлов

Фото перед загрузкой сжимаются до ~1400 px, так что занимают около 200–400 КБ. Видео загружаются как есть, лимит 50 МБ на файл (бесплатный тариф Supabase даёт 1 ГБ хранилища), поэтому для роликов с техникой удобнее вставлять ссылку на YouTube — она откроется прямо в карточке.

Бакет публичный: загружать и удалять файлы можете только вы, но файл открывается любым, у кого есть его ссылка (ссылки случайные и нигде не публикуются). Для фото тренажёров этого достаточно; если нужно полностью закрыть доступ, бакет можно сделать приватным и перейти на подписанные ссылки (`createSignedUrl`).

## Устройство данных

- `exercises` — библиотека упражнений. Упражнение, которое уже встречается в тренировках, не удаляется, а скрывается из библиотеки, чтобы сохранить историю.
- `workouts` — тренировки с датой, названием, заметками и отметкой о выполнении.
- `workout_exercises` — упражнения внутри тренировки с порядком.
- `sets` — подходы: плановые повторения и вес, фактические повторения и вес, отметка о выполнении.
