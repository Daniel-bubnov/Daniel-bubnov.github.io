# Подход — дневник тренировок

Личное веб-приложение для планирования тренировок. Хостинг — GitHub Pages, данные — Supabase.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Само приложение |
| `config.js` | Адрес проекта Supabase и публичный ключ. **Ваши ключи теперь живут здесь** |
| `schema.sql` | Полная схема базы — для нового проекта |
| `migration.sql` | Обновление уже существующей базы до версии 2.0 |

## Обновление с первой версии

1. **База.** Supabase → SQL Editor → New query → вставьте `migration.sql` → Run. Он только добавляет три колонки (время отдыха упражнения, начало и конец тренировки), данные не трогает.
2. **Ключи.** Откройте старый `index.html`, скопируйте оттуда адрес проекта и ключ и вставьте их в `config.js`:
   ```js
   window.APP_CONFIG = {
     supabaseUrl: 'https://xxxxxxxx.supabase.co',
     supabaseKey: 'sb_publishable_…',
   };
   ```
3. **GitHub.** Загрузите в репозиторий новые `index.html` и `config.js` (Add file → Upload files), замените старый `index.html`. Через минуту-две обновите страницу.

Дальше при обновлениях достаточно заменять только `index.html` — ключи в `config.js` останутся на месте.

## Установка с нуля

1. Создайте проект на supabase.com.
2. SQL Editor → вставьте `schema.sql` → Run. Создадутся таблицы, защита RLS и хранилище `media` для фото и видео.
3. Authentication → Users → Add user → Create new user: ваш email и пароль (галочка Auto Confirm User).
4. Authentication → Sign In / Providers → выключите «Allow new users to sign up», чтобы никто больше не мог зарегистрироваться.
5. Впишите адрес и ключ в `config.js`:
   - Project URL — кнопка **Connect** вверху проекта или Project Settings → Data API;
   - ключ — Project Settings → API Keys → **Publishable key** (или legacy **anon**). Secret / service_role ключ сюда вставлять нельзя.
6. Создайте репозиторий на GitHub, загрузите `index.html` и `config.js`, затем Settings → Pages → Deploy from a branch → `main` / root.

Публичный ключ в открытом репозитории — это нормально: данные защищены входом по паролю и правилами RLS, чужой пользователь их не увидит.

## Что умеет

**План.** Итоги недели (выполнено, поднятый вес, сколько недель подряд вы тренируетесь), календарь с отметками запланированных и выполненных дней, список ближайших тренировок. Новую тренировку можно собрать с нуля или повторить прошлую в один тап.

**Тренировка.** Для каждого упражнения — план и фактические вес и повторения по подходам, подсказка «прошлый раз» и текущий рекорд. Галочка подставляет план, если факт не вписан. Прогресс-бар, длительность, заметки к тренировке и к отдельному упражнению. Кнопка «Завершить» показывает итог: время, подходы, объём, новые рекорды.

**Таймер отдыха.** Запускается сам после отмеченного подхода, ±15 секунд, сигнал и вибрация в конце, экран не гаснет, пока идёт отсчёт. Время отдыха задаётся по умолчанию в настройках или отдельно для упражнения.

**Рекорды.** Если вес в подходе выше вашего лучшего результата, подход подсвечивается золотым и появляется уведомление.

**Упражнения.** Библиотека карточками с фото тренажёра, по группам мышц, с поиском. В карточке — фото, видео техники (YouTube или свой файл до 50 МБ), заметки по настройкам тренажёра, рекорд и дата последнего выполнения.

**Прогресс.** Общая статистика, список упражнений с мини-графиками и рекордами. По каждому упражнению — график максимального веса, расчётного 1ПМ, объёма или повторений и полная история.

**Настройки** (кнопка с ползунками в шапке): таймер, звук, вибрация, тема (авто, светлая, тёмная), скачивание резервной копии всех данных в JSON, выход.

## Если что-то не работает

- **Ошибка «Could not find the … column»** — не выполнен `migration.sql`.
- **«Осталось подключить базу»** — не заполнен `config.js` или он не загружен на GitHub рядом с `index.html`.
- **Таймер на iPhone.** Если свернуть браузер, iOS приостанавливает страницу: сигнал может не прозвучать, но при возвращении таймер покажет верное время. Надёжнее держать приложение открытым — во время отсчёта экран не гаснет сам.
- **Установка на телефон.** Safari → Поделиться → «На экран Домой». Появится иконка «Подход», приложение откроется без адресной строки.
